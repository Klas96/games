# games

Web builds of my games, served by GitHub Pages at <https://klasholmgren.se/games/>.

- `echoes-of-elysium/` — [Echoes of Elysium](https://klasholmgren.se/games/echoes-of-elysium/), deployed automatically by the release workflow in Klas96/echoes-of-elysium on every `v*` tag.

The deploy replaces `main` with a single orphan commit each time, so history never accumulates. Do not commit here by hand expecting it to persist.
